File folder includes:

1. MP285.zip - contains Windows application Mp285.exe used for object navigation under microscope
   by PC controlled 3DMS-285 micromanipulator (Sutter Inc) connected with via serial port.
The captured image have to be inserted into application XY-plane to visually move object
under microscope objective with high accuracy adjusted by image scale factor.            

2. User.zvt - VBA macro for AxioVision imaging software (Zeiss)  

See ResearchGate link for details: 
https://www.researchgate.net/publication/289372664_multidimensional_imaging_of_brain_slices_or_cell_cultures_acquisition_and_analysis
